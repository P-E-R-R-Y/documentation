Detailed Description

Une application a boucle. Elle tourne seule, ou se fait ticker.

On en herite pour remplir event / update / display. 

class MyApp : public IApp {
    void event() override   { ... }
    void update() override  { if (done) stop(); }
    void display() override { ... }
};

ITickable est publiquement herite : c'est ce qui permet a un hote de la piloter frame par frame au lieu de lui ceder la boucle.
