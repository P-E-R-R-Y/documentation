Detailed Description

La manette numero _index, ouverte a la construction.

SDL_GameController normalise deja les boutons : pas de table d'indices bruts a deviner comme chez sfml, l'enum du contrat se pose dessus presque un pour un.

SDL_Gamepad normalise deja les boutons : pas de table d'indices bruts a deviner comme chez sfml, l'enum du contrat se pose dessus presque un pour un.
