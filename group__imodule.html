Detailed Description

imodule

version: 1.0.0

‍The contract every loadable module answers to.

One interface, one file. A module says what it is and who it is — nothing else. Everything about finding, loading and keeping track of those modules lives in modulemanager.

class IModule {
public:
virtual ~IModule() = default;
virtual const char *type() const = 0; // "graphic", "audio", ...
virtual const char *name() const = 0; // "raylib", "sfml", ...
};
