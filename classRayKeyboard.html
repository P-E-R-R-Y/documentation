Detailed Description

raylib keyboard, read straight off the native state queries.

IsKeyPressed() compares currentKeyState and previousKeyState, two array lookups : nothing is consumed, so any number of readers get the same answer anywhere in the frame. raylib swaps the two arrays inside EndDrawing(), which is why the frame boundary is endDraw().

This is the behaviour the contract asks for, and the one the other vendors are aligned on.

Every key HELD right now - like isKeyDown, without having to name the key.
